
# Web Development Basics

## 1. Difference between Frontend, Backend, and Full-Stack Development
**Frontend:** The part of a website users interact with directly. It includes design, layout, and visuals (HTML, CSS, JS).  
*Example:* The user interface of Facebook.  
**Backend:** The server-side logic that handles data processing and storage.  
*Example:* Facebook servers managing user posts and authentication.  
**Full-Stack:** A developer who works on both frontend and backend.  
*Example:* A developer who creates both the Facebook login page and the logic behind it.

---

## 2. Client-Server Model Diagram
```
Client (Browser) → Internet → Web Server → Database → Web Server → Client (Response)
```

---

## 3. How a Browser Requests and Displays a Web Page
1. User enters a URL in the browser.  
2. Browser sends an HTTP request to the web server.  
3. Server processes the request and sends back an HTML response.  
4. Browser renders the HTML, CSS, and JavaScript to display the webpage.

## 5. Web Server and Examples
A web server stores, processes, and delivers web pages to users.  
**Examples:** Apache, Nginx, Microsoft IIS, Node.js, LiteSpeed.

---

## 6. Roles in a Web Project
- **Frontend Developer:** Designs and builds the website interface.  
- **Backend Developer:** Handles server logic and APIs.  
- **Database Administrator:** Manages and secures data stored in databases.

---

## 8. Static vs Dynamic Websites
| Type | Description | Example |
|------|--------------|----------|
| Static Website | Content doesn’t change | Portfolio site built with HTML & CSS |
| Dynamic Website | Content changes based on user interaction or database | Amazon |
