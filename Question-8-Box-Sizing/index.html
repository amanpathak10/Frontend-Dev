Box-Sizing Comparison

Understanding content-box vs border-box

Default: content-box

Width: 300px

Padding: 20px

Border: 5px

How it works:

Total width = width + padding + border

Total width = 300px + 40px + 10px = 350px

The padding and border are added OUTSIDE the specified width.

Modern: border-box

Width: 300px

Padding: 20px

Border: 5px

How it works:

Total width = width (includes padding and border)

Total width = 300px

The padding and border are included INSIDE the specified width.
